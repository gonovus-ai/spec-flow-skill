# SpecFlow Skill

This repository is the public release projection of the canonical private
`gonovus-ai/spec-flow` source. Send Skill changes to the source repository; do not edit
the projection directly.

Install SpecFlow for Codex at user scope from this exact release with either
supported installer:

```bash
gh skill install gonovus-ai/spec-flow-skill specflow@skill-v0.2.5 --agent codex --scope user
npx --yes skills@1.5.23 add https://github.com/gonovus-ai/spec-flow-skill/tree/skill-v0.2.5/skills/specflow --global --agent codex --yes
```

Install the same release for Claude Code at user scope:

```bash
gh skill install gonovus-ai/spec-flow-skill specflow@skill-v0.2.5 --agent claude-code --scope user
npx --yes skills@1.5.23 add https://github.com/gonovus-ai/spec-flow-skill/tree/skill-v0.2.5/skills/specflow --global --agent claude-code --yes
```
